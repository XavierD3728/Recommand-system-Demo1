# 数据管理目录

此目录包含推荐系统所需的所有数据文件。

## 文件说明

1. `template.csv` - 交易数据模板文件
   - 用于展示正确的数据格式
   - 可以基于此模板创建新的交易数据文件
   - 包含示例数据，展示了正确的数据格式和时间戳格式

2. `categories.csv` - 商品类别管理文件
   - 存储所有商品及其对应的类别信息
   - 系统会自动维护此文件
   - 可以手动编辑，但需要确保格式正确

## 数据格式说明

### 交易数据 (template.csv)
- 必须包含以下列：
  - `user_id`：用户ID（数字）
  - `item_id`：商品ID或名称（字符串）
  - `timestamp`：交易时间（YYYY-MM-DD 或 YYYY-MM-DD HH:MM:SS）
- CSV文件必须包含表头
- 时间戳格式必须统一
- 编码推荐使用UTF-8

### 类别数据 (categories.csv)
- 必须包含以下列：
  - `item_id`：商品ID或名称（与交易数据中的item_id对应）
  - `category`：商品类别名称
- 新商品会自动添加到此文件，初始类别为"未分类"
- 可以通过Web界面或直接编辑此文件来更新类别

## 数据管理建议

1. **备份管理**
   - 定期备份categories.csv文件
   - 在进行大规模数据更新前备份现有数据

2. **数据更新**
   - 优先使用Web界面更新数据
   - 如果直接编辑文件，请确保遵循正确的格式
   - 更新后重启系统以确保更改生效

3. **数据验证**
   - 新数据上传前，请检查格式是否符合要求
   - 确保时间戳格式统一
   - 验证商品ID的一致性

4. **类别管理**
   - 保持类别名称的一致性
   - 定期检查并更新"未分类"商品
   - 通过Web界面管理类别以避免格式错误

## 注意事项

1. 不要删除template.csv和categories.csv文件
2. 保持文件的UTF-8编码以支持中文
3. 确保数据文件中不包含重复记录
4. 定期清理不再使用的数据文件
