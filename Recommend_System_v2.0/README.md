# 基于关联规则的商品推荐系统

## 项目简介
这是一个基于关联规则的商品推荐系统，使用 Python Flask 框架开发。系统通过分析用户的购买历史，使用 Apriori 算法挖掘商品间的关联规则，为用户提供个性化的商品推荐。

## 功能特点
- 基于 Apriori 算法的关联规则挖掘
- 个性化商品推荐
- 商品类别管理
- 关联规则可视化
- 数据管理和导入
- 实时数据表查看

## 系统界面

### 1. 主页面布局
系统采用清晰的卡片式布局，主要分为以下几个部分：

#### 1.1 推荐模块（左侧）
- **获取推荐**
  - 用户选择下拉框
  - 推荐数量调整（1-10）
  - "获取推荐"按钮

- **推荐结果显示**
  - 历史购买记录列表
  - 推荐商品列表（含置信度、支持度、提升度）

#### 1.2 关联规则分析（右侧）
- 折叠面板式展示
- 按商品类别分组显示规则
- 每个规则显示：
  - 商品级规则
  - 类别级规则
  - 置信度
  - 支持度
  - 提升度

#### 1.3 数据管理
- CSV文件上传功能
- "查看数据表"按钮（新窗口打开）
- 数据更新状态提示

#### 1.4 商品类别管理
- 表格式布局
- 显示所有商品及其当前类别
- 类别修改下拉选择
- 支持添加新类别

### 2. 数据表查看页面
- 响应式表格布局
- 支持打印功能
- 清晰的表头和数据展示

## 使用说明
1. **获取推荐**
   - 选择用户ID
   - 设置推荐数量（默认5个，最多10个）
   - 点击"获取推荐"按钮
   - 系统显示用户历史购买记录和推荐商品

2. **查看关联规则**
   - 在右侧面板查看不同类别的关联规则
   - 点击类别标题展开/折叠规则详情
   - 查看规则的支持度、置信度和提升度

3. **数据管理**
   - 点击"选择文件"上传新的CSV数据
   - 点击"查看数据表"在新窗口查看完整数据
   - 支持数据表打印功能

4. **商品类别管理**
   - 在表格中查看所有商品及其类别
   - 使用下拉菜单修改商品类别
   - 选择"+ 添加新类别"创建新类别

## 数据格式要求
上传的CSV文件必须包含以下列：
- `user_id`：用户ID
- `item_id`：商品ID
- `timestamp`：购买时间

示例：
```csv
user_id,item_id,timestamp
1,手机,2024-01-01
1,耳机,2024-01-01
2,平板,2024-01-02
```

## 算法说明
系统使用 Apriori 算法进行关联规则挖掘，主要指标包括：
- **支持度**：表示规则在所有交易中出现的频率
- **置信度**：表示规则的可靠程度
- **提升度**：表示规则的相关性强度

## 快速启动指南

### 首次使用

1. 确保已安装所有依赖：
   ```bash
   pip install -r requirements.txt
   pip install pywin32
   ```

2. 以管理员身份运行 `start_service.bat`
   - 右键点击文件
   - 选择"以管理员身份运行"
   - 等待服务启动完成

3. 打开 `quick_access.html` 访问系统
   - 或直接访问 http://localhost:5000

### 日常使用

1. 启动服务：运行 `start_service.bat`
2. 停止服务：运行 `stop_service.bat`
3. 快速访问：打开 `quick_access.html`

### 服务管理

- 服务名称：RecommendationSystem
- 服务显示名称：Recommendation System Service
- 日志文件：`recommendation_service.log`

### 故障排除

1. 如果服务无法启动：
   - 检查是否以管理员权限运行
   - 查看 `recommendation_service.log` 中的错误信息
   - 确保所有依赖包都已正确安装

2. 如果网页无法访问：
   - 确认服务是否正在运行
   - 检查防火墙设置
   - 确保端口 5000 未被其他程序占用
